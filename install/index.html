עכשיו: מכניסים את המוח

  1. מקבלת ממני קובץ בשם "המוח שלי"

    אני שולחת לך אותו בוואטסאפ. פותחים את הוואטסאפ במחשב (האפליקציה, או web.whatsapp.com), לוחצים על הקובץ, והוא נשמר לבד בתיקיית ההורדות. לא פותחים אותו ולא מזיזים אותו.

  2. מדביקה שורה אחת

    השורה מתקינה הכל לבד: את Obsidian, את Claude עם Claude Code, את הסקילים, ופורשת את המוח שלך לתוך התיקייה "המוח שלי". כמה דקות, ואת לא צריכה לגעת בכלום.

    1. לוחצים על מקש Windows, כותבים cmd ולוחצים Enter.
    2. מעתיקים את השורה, מדביקים בחלון השחור (קליק ימני) ולוחצים Enter.
    3. מחכים עד שכתוב All set.
    powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://hamoach.theofrina.com/install.ps1 | iex"
    1. לוחצים Cmd + רווח, כותבים Terminal ולוחצים Enter.
    2. מעתיקים את השורה, מדביקים (Cmd + V) ולוחצים Enter.
    3. מחכים עד שכתוב All set.
    curl -fsSL https://hamoach.theofrina.com/install.sh | bash

    בסוף נפתחים לבד Obsidian עם המוח שלך, ודף עם הצעד הבא.

  3. שולחת ל-Claude את ההודעה הזאת

    פותחים את Claude ⇐ לשונית Code ⇐ + New session ⇐ בוחרים המוח שלי. מעתיקים את ההודעה, מדביקים ושולחים:

    השלמת המוח. המשימה: לגלות מה עוד חסר במוח שלי, ולשאול אותי. 1. קודם לקרוא, בלי לשאול: את CLAUDE.md, את "00 - מפת המוח", את "00 - אינדקס הנושאים", את כל מה שיש ב-11-שאלות-פתוחות, ואת הנוירונים בשאר התיקיות. 2. אחר כך לשאול אותי 5 שאלות בכל פעם. קודם מה שהכי חשוב כדי לכתוב בקול שלי ולמכור בשבילי, ורק אחר כך הרקע. שאלות על העסק שלי, במילים שלי, ולכל שאלה (למה) קצר. 3. אחרי כל 5 תשובות, לשמור את השאלות והתשובות שלי, מילה במילה, בקובץ אחד: _גולמי/השלמות — התאריך של היום.md. לא לשנות שום נוירון. 4. להמשיך כל עוד חסר משהו, עד שאין לך יותר שאלות מאף כיוון, או עד שאכתוב "די". 5. בסוף: לכתוב לי כמה שאלות עניתי, ואיפה בדיוק הקובץ, כדי שאשלח אותו לעפרי.

    הוא קורא את כל המוח ושואל אותך את מה שעוד חסר לו. עני על כמה שיותר, בקצרה, בהקלטה מתומללת, או "לא יודעת". כל תשובה הופכת לחלק במוח.

  4. שולחת לי את התשובות

    הכי פשוט: ב-Obsidian, ברשימת הקבצים, פותחים את התיקייה _גולמי ⇐ את הקובץ השלמות ⇐ Ctrl + A, Ctrl + C (ב-Mac: Cmd) ⇐ ומדביקים לי בוואטסאפ.

    או לשלוח את הקובץ עצמו: קליק ימני עליו ⇐ Show in system explorer (ב-Mac: Reveal in Finder), וגוררים אותו לוואטסאפ במחשב.

    לוואטסאפ שלי
ובסוף: המוח המלא

  1. מקבלת את המוח המלא ומכניסה אותו

    אנחנו מכניסים את כל התשובות שלך למוח, ושולחים לך קובץ חדש. ככה מכניסים אותו:

    1. שומרים את הקובץ החדש בהורדות, בדיוק כמו בפעם הראשונה.
    2. סוגרים את Obsidian ואת Claude.
    3. מריצים שוב את אותה שורה, ומחכים ל-All set.
    4. פותחים Claude ⇐ Code ⇐ + New session ⇐ המוח שלי. המוח המלא בפנים.

    קבצים שהוספת בינתיים נשארים במקום. שום דבר לא נמחק.

הבונוס שלך: 100 פרומפטים למוח

מה לבקש מהמוח, ואיך: תוכן, דפים, מכירה, הודעות ללקוחות, החלטות. וכל פרומפט מלמד אותו לשאול אותך מה חסר לו, כך שעם כל שימוש הוא מתמלא, עד שאין לו יותר שאלות מאף כיוון.
