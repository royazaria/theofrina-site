המוח שלך בפנים.

  1. פתחי את Claude ובחרי את התיקייה

    Claude⇐Code⇐+ New session⇐המוח שלי

    בפעם הראשונה Claude יבקש להתחבר. מתחברים עם החשבון של המנוי. התיקייה "המוח שלי" נמצאת בתיקיית המשתמש שלך.

  2. שלחי לו את ההודעה הזאת

    השלמת המוח. המשימה: לגלות מה עוד חסר במוח שלי, ולשאול אותי. 1. קודם לקרוא, בלי לשאול: את CLAUDE.md, את "00 - מפת המוח", את "00 - אינדקס הנושאים", את כל מה שיש ב-11-שאלות-פתוחות, ואת הנוירונים בשאר התיקיות. 2. אחר כך לשאול אותי 5 שאלות בכל פעם. קודם מה שהכי חשוב כדי לכתוב בקול שלי ולמכור בשבילי, ורק אחר כך הרקע. שאלות על העסק שלי, במילים שלי, ולכל שאלה (למה) קצר. 3. אחרי כל 5 תשובות, לשמור את השאלות והתשובות שלי, מילה במילה, בקובץ אחד: _גולמי/השלמות — התאריך של היום.md. לא לשנות שום נוירון. 4. להמשיך כל עוד חסר משהו, עד שאין לך יותר שאלות מאף כיוון, או עד שאכתוב "די". 5. בסוף: לכתוב לי כמה שאלות עניתי, ואיפה בדיוק הקובץ, כדי שאשלח אותו לעפרי.

    הוא קורא את כל המוח ושואל אותך את מה שעוד חסר לו. עני על כמה שיותר. בסוף הוא שומר הכל בקובץ השלמות בתיקייה _גולמי: פותחים אותו ב-Obsidian, מעתיקים הכל (Ctrl + A, Ctrl + C), ומדביקים לי בוואטסאפ.

  3. פתחי את המפה

    ב-Obsidian, ברשימת הקבצים, לוחצים על המפה. זה העסק שלך, מבחוץ.

  4. חברי את הג׳ימייל והדרייב (פעם אחת)

    נכנסים ל-claude.ai ⇐ בתפריט Customize (או Settings) ⇐ Connectors ⇐ ליד Gmail לוחצים Connect ומאשרים עם החשבון בגוגל. אותו דבר ל-Google Drive.

    מעכשיו אפשר לבקש: "תמצא בדרייב את המצגת של...", "תכתוב טיוטת תשובה למייל של...". מיילים נשארים טיוטה עד שאת מאשרת ושולחת.

  5. קיבלת ממני את המוח המלא?

    שמרי את הקובץ החדש בהורדות, סגרי את Obsidian ואת Claude, והריצי שוב את אותה שורה. כשכתוב All set, פותחים Claude ⇐ Code ⇐ + New session ⇐ המוח שלי. המוח המלא בפנים, וקבצים שהוספת בינתיים נשארים.
